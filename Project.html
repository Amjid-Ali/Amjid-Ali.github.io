Projects

Open-source computer vision and RAG projects, built to extend the production and research work described in my CV and publications. Full code and documentation for each is on GitHub.

Open-Source Projects

  • low-light-adverse-condition-detection

    CLAHE-based low-light/glare enhancement + YOLOv8 detection. The general version of the smoke/glare/night problem I solve daily at POSCO.

  • multi-object-tracking-occlusion

    ByteTrack/BoT-SORT with an added recovery layer that re-links tracks after brief occlusion instead of assigning a new ID.

  • multi-camera-person-vehicle-reid

    Cross-camera person/vehicle re-identification using CLIP embeddings and cosine-similarity matching.

  • depth-based-safety-zone-detection

    Monocular depth (MiDaS) + YOLOv8 to flag objects entering a danger zone around equipment, from a single RGB camera.

  • few-shot-anomaly-detection-patchcore

    Memory-bank anomaly detection (PatchCore-style) — no training step, works from a handful of normal reference images.

  • open-vocab-defect-detection-vlm

    Open-vocabulary defect detection with OWL-ViT: new defect types added by text prompt, not retraining.

  • realtime-fire-smoke-segmentation

    Pixel-level fire/smoke segmentation via a published HSV color model, upgrading my bounding-box fire detector.

  • yolo-edge-quantization-benchmark

    Benchmarking harness for YOLO FP32/FP16/INT8 export on real target hardware — Jetson, GPU, or CPU.

  • sim2real-domain-adaptation

    Training-free color/lighting adaptation for Unity-rendered synthetic training data, closing part of the sim-to-real gap.

  • video-anomaly-recognition-visual

    Vision-only video anomaly recognition via a clip-level memory bank — the visual counterpart to my AVAR-Net thesis.

  • Anomaly-Detection-in-Industrial-Inspection

    Unsupervised anomaly detection on the MVTec AD dataset using a convolutional encoder–decoder.

  • Automatic-Number-Plate-Recognition-using-Yolov9

    License plate detection (YOLOv9) and text recognition (EasyOCR).

  • Car-Detection-using-Drone

    Car detection in aerial drone imagery with MobileNet-SSD.

  • Fire-Detection-YOLOv8

    Fire detection with YOLOv8, with both a CLI and a Streamlit web interface.

  • RAG_Chatbot

    Retrieval-augmented document question answering over user-uploaded PDFs.

  • graphrag-knowledge-graph-retrieval

    Knowledge-graph-based RAG: retrieves via graph traversal instead of pure vector similarity, for multi-hop questions plain RAG handles badly.

  • corrective-rag-self-grading

    Corrective RAG (CRAG): grades retrieved context before answering, rewriting and retrying the query when retrieval quality is poor.

  • multimodal-rag-text-image

    RAG over PDFs with both text and images — images are captioned and indexed alongside text in a unified retrieval space.

  • react-agent-self-verification

    A ReAct tool-using agent that checks its own draft answer against actual tool observations before finalizing.

  • multi-agent-task-orchestrator

    Planner + specialized worker agents (researcher/writer/critic) + aggregator, with orchestration logic kept inspectable in Python.

  • vision-grounded-tool-agent

    Agent that chooses which CV tool (detection, OCR, captioning) to call per question, instead of running a fixed pipeline.

  • safety-event-triage-agent

    Reasons about severity and escalation for a detection event, the judgment layer on top of my production detection work.
